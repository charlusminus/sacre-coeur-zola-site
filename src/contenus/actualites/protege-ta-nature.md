Toujours dans le cadre du projet biodiversité, les CM1-CM2 ont décidé de mener une action de sensibilisation à la préservation de l'environnement proche, c'est-à-dire dans l'école !

Ils ont réalisé des affiches qui ont été installées dans les cours de l'établissement, puis sont passés dans les classes pour les présenter.

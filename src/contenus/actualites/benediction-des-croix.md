---
titre: "La bénédiction des croix de la nouvelle école"
date: 2022-11-08
resume: "Le lendemain de l'arrivée dans les nouveaux locaux, le curé de la paroisse est venu bénir les croix de toutes les salles."
rubrique: "Pastorale"
---

Mardi 8 novembre 2022, le lendemain de notre arrivée dans les nouveaux locaux, le père Albert, curé de notre paroisse, est venu bénir les croix. Elles ont ensuite été accrochées dans toutes les salles de l'école.

Les élèves de toutes les classes, réunis dans le forum, ont écouté le prêtre puis chanté le « Je vous salue Marie ».
